216, 꼬질이를 잡아라

생선 도둑 길고양이를 몰래 따라잡기

못돼 보이는 길고양이 꼬질이가 이음수산 생선을 물고 달아났어요!

  • 꾹 누르면 216이 달리고, 손을 떼면 주르륵 미끄러지다 멈춰요.
  • 멈추면 216이 📦 이음수산 택배 상자를 뒤집어써요. 꼬질이 눈엔 그냥 상자예요.
  • 꼬질이가 뒤돌아볼 때 움직이고 있거나 상자를 다 못 썼으면 들켜요. 꼬질이가 놀라 멀리 달아나요.
  • 돌아보기 전엔 꼭 꼬리가 바짝 서요. 그때 떼야 해요. 물바닥에선 더 미끄러지니 미리 떼요.
  • 꼬질이가 앉아서 그루밍을 하면 눈을 감아요. 그때가 마음껏 달릴 기회!
  • 돌아보기 직전에 딱 멈춰 상자를 쓰면 아슬아슬! 연속으로 노려 봐요.
  • 꼬질이가 앞의 초록 띠 안에 들어오면 ⤴ 덮치기! 꼬질이가 안 볼 때 누르면 꼭 잡혀요. 가운데 발자국에 맞추면 🎯 완벽한 덮치기.
  • 꼬질이가 골목까지 가면 놓쳐요. 딱 한 판! 덜 들키고 빨리 잡을수록 좋아요.
